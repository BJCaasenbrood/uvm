Getting Started

1. Install uvm

Put the toolbox folder on the path, then let uvm add itself to your startup.m so it is available in every session:

>> addpath('/path/to/UVmatlab/toolbox')
>> uvm setup

The hook that uvm setup adds also activates the project in the folder MATLAB starts in. Remove it again with uvm setup --remove.

Check that git can be found:

>> uvm version

2. Create a project

>> cd ~/work/my_analysis
>> uvm init
Initialized project "my_analysis" in /home/me/work/my_analysis

This writes uvm.json:

{
  "name": "my_analysis",
  "version": "0.1.0",
  "matlab": ">=R2024a",
  "toolboxes": [],
  "paths": ["."],
  "dependencies": {}
}

Using MATLAB Projects? Run uvm init --project instead; opening the project then activates its packages automatically. See MATLAB Projects.

3. Point uvm at your registry

A registry maps package names to git URLs. If your team has one, register it once per machine:

>> uvm registry add work git@git.company.local:matlab/registry.git

No registry yet? You can add packages by URL instead — see step 4 — or set one up.

4. Add dependencies

From a registry, by name:

>> uvm add signal_utils           % newest version, saved as "^1.4.0"
>> uvm add plot_tools@~2.1        % a specific range

Straight from a git repository:

>> uvm add git@git.company.local:lab/daq_tools.git --tag v0.4.0
>> uvm add https://github.com/someone/fancy_lib.git --branch main
>> uvm add ../local_lib                                  % a folder on disk

Each uvm add updates uvm.json, resolves versions into uvm.lock, installs what is missing and activates the project, so the functions are usable straight away.

5. Use it

>> uvm list
Package              Version      Commit     Source
daq_tools            0.4.0        3f9c2a1b   git@git.company.local:lab/daq_tools.git
signal_utils         1.4.0        a81d07e2   git@git.company.local:matlab/signal_utils.git

>> uvm run analysis.m

6. Share it

Commit uvm.json and uvm.lock. A colleague clones the project and runs:

>> uvm sync

and gets exactly the same commits of every package.
