uvm — project and package manager for MATLAB

uvm gives every MATLAB project its own list of dependencies, resolves them to exact versions, and puts exactly those packages on the path. You declare what you need in uvm.json, uvm records what it picked in uvm.lock, and anyone who checks out the project gets the same code with a single uvm sync.

Packages are ordinary git repositories, and versions are git tags. A git server you already have — GitLab, Bitbucket, Gitea, or GitHub — is all the infrastructure you need.

>> uvm init
>> uvm add signal_utils
>> uvm sync
>> uvm run analysis.m

Requirements

  • MATLAB R2023a or newer.
  • git installed and on the system path. uvm uses the same git you use in a terminal, so your SSH keys, credential helpers and proxy settings apply.
